How to black out text in a PDF permanently

Drawing a black shape or highlight over PDF text usually just adds a layer on top. The words are still in the file — select-all and paste, and they come right back. Permanent blackout means the text is removed, not hidden.

Why black boxes and highlights fail

A PDF page is a stack of objects: text, images, vector shapes, annotations. Adding a black rectangle — with a drawing tool, a comment, or a “black highlighter” — puts a new object on top. The text object below is untouched, so it can still be selected, copied, searched, or extracted with any PDF text tool. This mistake has repeatedly exposed information in publicly filed documents where the “redacted” text could simply be copied out.

Two ways to do it properly

  • True redaction in a full PDF editor — tools with a dedicated Redact function (then “Apply redactions”) remove the underlying content. Make sure you apply, not just mark.
  • Flatten to images — what DocBurn does: render each page to pixels with the black burned in. Simple and hard to get wrong, at the cost of the output being non-searchable.

Quick self-check after exporting

  • Ctrl/Cmd+A on each page and paste into a text editor — redacted words must not appear.
  • Search the PDF for a redacted name or number.
  • Also check document metadata (title, author) and file names for sensitive info.

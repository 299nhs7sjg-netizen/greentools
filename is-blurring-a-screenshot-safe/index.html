Is blurring a screenshot safe?

Short answer: not for text you actually need hidden. Blur and pixelation keep a transformed version of the original pixels in the image. For short, predictable content — emails, card digits, API keys, passwords in a known font — that can be enough to reconstruct or brute-force the original. Solid black fill replaces the pixels entirely.

What to do instead

  1. Use an opaque fill. Cover sensitive text with a 100%-opaque black (or any solid color) box.
  2. Flatten the export. Make sure the box is part of the exported pixels, not a separate layer or annotation.
  3. Remove metadata. Re-encode the image so EXIF data from the original isn’t carried along.
  4. Verify. Open the exported file at full zoom and try adjusting brightness/contrast — nothing should appear.

Why blur and pixelate can be undone

  • Pixelation is deterministic. Each block is the average of the pixels beneath. If an attacker knows (or guesses) the font, size, and background, they can render candidate text, pixelate it the same way, and match blocks. Open-source tools like Depix demonstrated this on pixelated passwords in screenshots.
  • Weak blur keeps structure. A small-radius blur leaves letter shapes and word lengths visible; sharpening or simply guessing from context can reveal the content.
  • Swirl/distortion filters are reversible. Investigators have famously un-swirled a suspect’s face from photos because the filter was a reversible transform.
  • Semi-transparent markers can be seen through by boosting contrast.

When blur is fine

Blurring a background for aesthetics, or softening something that isn’t secret, is fine. The risk is using it as a security control for text or identities.

FAQ

Is a heavy blur safe?

A very strong blur over a large area reveals far less than light blur or pixelation, but it still leaves information like text length. Solid fill leaves none, so it’s the safer default.

Is pixelation safer than blur?

Not necessarily. Pixelation of text in a known font is one of the better-studied cases of reversal.

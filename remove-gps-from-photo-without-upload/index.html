Steps

  1. Open MetaGone. Any modern desktop or mobile browser.
  2. Add your photo. JPEG, PNG, or WebP. The file is read locally with browser APIs.
  3. Review what’s inside. See detected GPS latitude/longitude, camera make/model, timestamps, software, and XMP/C2PA markers.
  4. Scrub and download. MetaGone re-draws the image and re-encodes it, which drops EXIF/XMP blocks, then saves the clean copy.
  5. Keep the proof slip. Download the one-page report listing fields removed, with a timestamp and SHA-256 hashes of before/after files.

What GPS metadata reveals

Phone cameras can record latitude and longitude precise enough to identify a home or workplace, plus altitude and direction in some cases. Combined with the capture time, a single photo can reveal where you were and when.

Other no-upload ways

  • Windows — File Explorer → right-click → Properties → Details → “Remove Properties and Personal Information.”
  • macOS Preview — Tools → Show Inspector → the GPS tab (when present) → Remove Location Info.
  • Command line — exiftool -gps:all= photo.jpg removes GPS tags; exiftool -all= photo.jpg removes all metadata.
  • iPhone — see remove EXIF location from an iPhone photo.

Trade-off

Because MetaGone re-encodes the image in the browser, JPEG output is recompressed. At normal sharing sizes this is rarely noticeable; keep your original if you need a lossless archive.

FAQ

How do I know it isn’t uploading?

Open DevTools → Network while you scrub; there’s no request carrying the photo. MetaGone is a static site with no backend.

Does it remove everything?

It strips EXIF, GPS, and XMP as completely as is practical in-browser by re-encoding pixels. Pixel-level watermarks are part of the image itself and are not metadata.

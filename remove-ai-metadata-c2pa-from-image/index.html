How to remove AI metadata (C2PA) from an image

Images from AI generators and some editing apps and cameras can carry provenance metadata: C2PA “Content Credentials” manifests and XMP fields such as creator tool, editing history, and document IDs. These can reveal which software or account workflow produced a file. Here’s what they are and how to strip them locally.

What C2PA is

C2PA (Coalition for Content Provenance and Authenticity) is an open standard for attaching a signed provenance manifest to media — who or what created it and how it was edited. In JPEGs the manifest is typically stored in a JUMBF metadata box. It’s metadata, so re-encoding the pixels without copying that box removes it.

What stripping metadata can’t do

  • Invisible watermarks embedded in the pixels (some AI providers use these) are not metadata and survive a metadata scrub.
  • It doesn’t change what the image is. Removing provenance data does not make an AI image “not AI.” Platforms may still label or detect it, and some platforms’ rules require disclosure of AI-generated content — follow them.
  • Good reasons to strip it include privacy (account IDs, file paths, software histories) and reducing file size.

Other methods

  • exiftool -all= image.jpg removes EXIF/XMP and other metadata blocks it recognizes.
  • Screenshotting an image also drops embedded metadata but degrades quality.
